# AI 使用说明

## AI 辅助内容

本项目由 Codex 协助完成以下工作：

- 将题目拆解为输入、工具、Planner、执行循环、状态和验收场景；
- 生成 Python 初版实现、合成数据和 CLI；
- 设计幂等键、硬性时间保护、保存失败及步数上限；
- 编写自动化测试、运行示例和五份交付文档；
- 执行测试并根据实际结果补充评估材料。

## 人工应重点审查和修改的内容

提交者需要在最终提交前亲自完成并记录以下事项：

1. 阅读 `src/planners.py`，确认真实模型提示词没有把草稿描述成发布结果；
2. 阅读 `src/tools.py`，确认业务规则与题目一致；
3. 独立运行 README 中的测试和冲突示例；
4. 使用自己的模型服务运行至少一次 `--planner llm`，检查模型是否返回合法动作；
5. 在本文件补充本人实际修改内容、原因及验证结果；
6. 在 README 中补充正式题号。

当前没有把尚未发生的“个人修改”虚构为已完成。以下模板供提交者填写：

```text
个人修改：
- 修改文件/逻辑：
- 修改原因：
- 验证命令：
- 验证结果：
```

## 验证方式

- 10 个自动化测试覆盖六项强制验收、步数上限、Trace 字段和两项对抗性动作校验；
- CLI 实际生成 7 份输出，其中重复场景执行两次；
- 保存失败进程退出码为 1，结果仍被写入输出文件供审查；
- 所有实际输出都包含 `published=false`。

## 使用边界

离线 Mock 的条件逻辑是测试替身，不作为 ReAct 智能效果证据。真实 ReAct 能力来自 `CompatibleLLMPlanner` 每轮基于最新观察选择动作。由于本次环境没有模型密钥，评估文档明确把真实模型效果列为未验证项。
